What I Built

งานนี้เป็นการสร้างเว็บไซต์ My First Learning Portfolio โดยเน้นการออกแบบให้เข้าใจสไตล์ของผู้เขียนเว็บมากที่สุดเพื่อแนะนำความเป็นตัวเองตกแต่งองค์ประกอบด้วยสีสันเพื่อความน่ารัก โดยภายในเว็บ

องค์ประกอบสำคัญในเว็บไซต์:

  • ส่วนหัว (Header): แสดงชื่อเว็บไซต์และคำอธิบายสั้นๆ
  • ส่วนแนะนำตัว (About Me): แสดงข้อมูลส่วนตัว พร้อมรูปภาพโปรไฟล์
  • อธิบายชิ้นงาน (What I Built): สรุปภาพรวมของเว็บไซต์และอธิบายหลักการ Client / Server
  • ขั้นตอนการพัฒนา (How I Built It): แสดงลำดับขั้นตอนการทำงาน และระบุแหล่งข้อมูลอ้างอิง
  • การสะท้อนความคิด (Reflection): สรุปปัญหาที่พบ สิ่งที่ได้เรียนรู้ และแนวทางการพัฒนาต่อ

How I Built It

ขั้นตอนการพัฒนางานชิ้นนี้:

  1. วางแผนโครงสร้างเนื้อหาตามโจทย์ที่อาจารย์ให้มา
  2. สร้างไฟล์ HTML โดยใช้ Semantic Elements (header, main, section, footer)
  3. สร้างไฟล์ style.css แยกต่างหากเพื่อจัดรูปแบบและ Layout
  4. ตรวจสอบความเรียบร้อยหน้าเว็บบอร์ดก่อนส่ง

เครื่องมือและแหล่งข้อมูลที่ใช้: ใช้ VS Code เป็นเครื่องมือหลักในการเขียนโค้ด และเปิดสไลด์การเรียนรู้ของอาจารย์ควบคู่ไปกับกูเกิล (เรื่องที่ไม่รู้) ในการทำงาน

Reflection
